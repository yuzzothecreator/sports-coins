# Sport Coins visual refinement

- Display and headings: Manrope Bold / ExtraBold.
- Body and controls: Inter Regular / Medium / SemiBold / Bold, loaded as explicit font faces for Android/iOS/web consistency.
- Primary navy: `#182139`; feature panels: `#111C33`.
- Accent gold: `#AB8951`; soft gold: `#F7F2E8`.
- Canvas: `#F5F7FA`; surfaces: white; borders: `#E6EAF0`.
- Secondary text: `#687386`; positive status: `#24745F`.
- Rounded cards: 20 px; controls: 12 px; status badges: pill.
- Clear main/section heading hierarchy, tabular score numerals, restrained shadows.
- Press and hover feedback, visible keyboard focus, 44 px minimum primary navigation targets.

Fonts are bundled from the Expo Google Fonts packages; there are no runtime Google Fonts requests. Shared typography resolves font weights to explicit assets. Existing demo interactions and backend boundaries are unchanged. Dark mode is not implemented by this refinement.
